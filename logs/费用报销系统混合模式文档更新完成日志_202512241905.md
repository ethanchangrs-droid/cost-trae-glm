## 3. 核心设计特点

### 3.1 混合填单模式架构
```
票据上传 → 多模态识别 → 双路径处理
                    ├─ 结构化提取 → 表格显示
                    └─ LLM分析 → 自然语言描述
```

### 3.2 用户交互流程
1. **票据识别**：用户上传票据照片，AI进行多模态识别
2. **信息展示**：结构化数据以表格形式显示，LLM描述以文本形式显示
3. **用户编辑**：用户可以编辑结构化数据和LLM生成的描述
4. **智能验证**：实时验证规则匹配和合规性

### 3.3 技术实现要点
- **多模态识别**：使用阿里云百炼平台的视觉模型
- **结构化提取**：OCR + 关键信息提取
- **智能描述**：LLM基于识别结果生成自然语言解释
- **混合验证**：结构化规则 + 自然语言规则协同验证
