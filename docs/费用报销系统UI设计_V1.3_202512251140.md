# 费用报销系统UI设计文档
**版本**: V1.3  
**创建日期**: 2025年12月25日  
**最后更新**: 2025年12月25日  
**更新内容**: 移除登录页面，增加用户管理页面，调整导航结构，增加用户选择弹窗组件

## 1. 设计概述

### 1.1 设计原则
- **简洁直观**：界面简洁明了，操作流程清晰
- **智能化**：突出LLM智能辅助功能
- **响应式**：适配不同屏幕尺寸
- **一致性**：保持设计风格和交互模式的一致性
- **无认证**：系统无需登录，直接进入主界面

### 1.2 设计风格
- **色彩方案**：以蓝色为主色调，体现专业和可信赖
- **字体**：使用系统默认字体，确保可读性
- **布局**：采用卡片式布局，信息层次清晰
- **图标**：使用Ant Design图标库，保持统一性

### 1.3 技术实现
- **UI框架**：Ant Design 5.x
- **样式方案**：CSS Modules + Less
- **响应式**：Flexbox + Grid布局
- **动画效果**：CSS3过渡动画

## 4. 组件设计规范

### 4.1 用户选择弹窗组件 (UserSelector)

#### 4.1.1 组件结构
```jsx
<UserSelector
  visible={boolean}           // 弹窗显示状态
  onCancel={Function}          // 取消回调
  onConfirm={Function}         // 确认回调，返回选中的用户信息
  title={string}              // 弹窗标题，默认"选择用户"
  multiple={boolean}          // 是否支持多选，默认false
/>
```

#### 4.1.2 交互设计
- **搜索功能**：支持按姓名实时搜索，搜索结果即时更新
- **选择方式**：点击表格行选择用户，选中行高亮显示
- **确认选择**：必须选择用户后才能确认，否则确认按钮禁用
- **取消操作**：点击取消或关闭弹窗，不返回任何数据

#### 4.1.3 样式规范
- **弹窗尺寸**：宽度600px，高度自适应
- **表格样式**：紧凑型表格，行高适中
- **选中状态**：浅蓝色背景，边框高亮
- **搜索框**：带搜索图标，聚焦时边框高亮

### 4.2 用户管理表格组件 (UserTable)

#### 4.2.1 表格列定义
- **ID列**：数字，居中对齐，宽度80px
- **姓名列**：文本，左对齐，宽度120px
- **工号列**：文本，左对齐，宽度120px
- **级别列**：标签显示，左对齐，宽度100px
- **创建时间列**：日期时间，左对齐，宽度160px
- **操作列**：按钮组，左对齐，宽度120px

#### 4.2.2 操作按钮设计
- **编辑按钮**：蓝色链接样式，带编辑图标
- **删除按钮**：红色链接样式，带删除图标，点击后显示确认弹窗

#### 4.2.3 分页设计
- **每页条数**：10条，支持切换为20、50、100条
- **页码显示**：显示当前页和总页数
- **快速跳转**：支持输入页码快速跳转

### 4.3 表单组件规范

#### 4.3.1 输入框设计
- **必填标识**：红色星号(*)显示在标签右侧
- **验证提示**：错误信息显示在输入框下方，红色文字
- **聚焦效果**：蓝色边框，阴影效果
- **禁用状态**：灰色背景，不可编辑

#### 4.3.2 选择器设计
- **下拉选项**：最大显示8个选项，超出时显示滚动条
- **搜索功能**：选项较多时支持搜索过滤
- **清空按钮**：支持一键清空选择

#### 4.3.3 按钮设计
- **主要按钮**：蓝色背景，白色文字，圆角4px
- **次要按钮**：白色背景，蓝色边框，蓝色文字
- **危险按钮**：红色背景，白色文字
- **禁用状态**：灰色背景，不可点击

## 5. 响应式设计

### 5.1 断点设置
