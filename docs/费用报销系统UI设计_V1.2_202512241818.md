# 费用报销系统UI设计文档
**版本**: V1.2  
**创建日期**: 2025年12月24日  
**最后更新**: 2025年12月24日  
**更新内容**: 更新费用报销页面为混合填单模式，支持结构化信息与LLM智能描述共存

## 1. 设计概述

### 1.1 设计原则
- **简洁直观**：界面简洁明了，操作流程清晰
- **智能化**：突出LLM智能辅助功能
- **响应式**：适配不同屏幕尺寸
- **一致性**：保持设计风格和交互模式的一致性

### 1.2 设计风格
- **色彩方案**：以蓝色为主色调，体现专业和可信赖
- **字体**：使用系统默认字体，确保可读性
- **布局**：采用卡片式布局，信息层次清晰
- **图标**：使用Ant Design图标库，保持统一性

### 1.3 技术实现
- **UI框架**：Ant Design 5.x
- **样式方案**：CSS Modules + Less
- **响应式**：Flexbox + Grid布局
- **动画效果**：CSS3过渡动画

- **规则类型选择**：单选按钮组，支持结构化、自然语言、混合规则三种模式

- **复杂度分析**：点击后显示加载动画，分析完成后展示复杂度评分和推荐存储方式
- **解析按钮**：根据规则类型执行不同的解析逻辑，解析成功后显示结构化/混合结果
- **结果预览**：以卡片形式展示解析结果，混合规则显示结构化和自然语言两部分
- **规则列表**：表格形式展示现有规则，包含复杂度评分，支持启用/禁用切换和验证测试
- **验证功能**：点击验证按钮可测试规则对示例数据的验证效果
