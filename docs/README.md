## 文档版本管理

### 版本命名规则
- 格式：`{文档类型}_V{主版本}.{次版本}_{创建日期时间}.md`
- 示例：`费用报销系统PRD_V1.3_202512251100.md`

### 版本更新流程
1. 创建新版本文档
2. 更新版本号和日期
3. 记录更新内容
4. 将旧版本移至archive目录

### 文档状态
- **最新版本**: docs/根目录下的文档
- **历史版本**: docs/archive/目录下的文档
- **草稿版本**: 以_draft结尾的文档
